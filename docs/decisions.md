# تصمیم‌های این جلسه

تاریخ ثبت: ۲۰۲۶-۱۰-۱۷. این سند برای انتقال زمینهٔ گفت‌وگو به همکار بعدی است. `design.md` مرجع رفتار فعلی کد است و این فایل دلیل انتخاب‌ها و ترتیب درخواست‌ها را نگه می‌دارد.

## دامنه و اجرا

1. کاربر برنامه‌ای **جدا از CLM** خواست که در هر پروژه و هر فلو قابل استفاده باشد. قالب قرارداد v2 فقط نمونه‌ای قابل‌ویرایش است.
2. شکل برنامه، وب‌اپ محلی مستقل در مرورگر با Python و SQLite انتخاب شد. پورت ابزار `127.0.0.1:8765` و backend محلی نمونهٔ CLM `127.0.0.1:8000` است.
3. واردکردن نسخهٔ جدید Swagger/OpenAPI باید کاتالوگ را به‌روزرسانی کند و فلو، نگاشت‌ها، متغیرها و تاریخچه را حفظ کند. عملیات حذف‌شده از schema به‌صورت «غایب» مشخص می‌شود.
4. مثال قراردادی از ورود و OTP تا **ارسال برای امضا** است. کاربر اجرای از هر نقطه و ادامه با متغیرهای ذخیره‌شده را خواست؛ درخواست تکراری POST موفق تأیید جداگانه دارد.
5. تاریخچه باید تمام JSON درخواست‌ها و پاسخ‌ها را به ترتیب همراه URL، وضعیت و علت خطا نشان دهد. درخواست تازه‌سازی توکن و retry هم جزو تاریخچه‌اند.

## طراحی تجربهٔ کاربر

6. رابط باید برای کاربر عمومی قابل‌فهم و تعاملی باشد، بدون حذف قابلیت‌های پیشرفته. ورودی‌های متغیر و OTP در مدال دریافت می‌شوند و هنگام نیاز به مقدار، مدال متغیر باز می‌شود.
7. دو نمای مکمل انتخاب شد: فهرست سریع و دیاگرام قابل drag and drop. دیاگرام فقط نمایش ترتیب نیست؛ شاخهٔ شرطی و حلقه باید واقعاً اجرا شوند.
8. کاربر برای دیاگرام بوم نقطه‌ای، ساخت گام با کشیدن و رهاکردن، اتصال با خط، حذف اتصال، تمام‌صفحه و بازشدن تنظیمات فقط پس از کلیک را خواست. اتصالات در جهت RTL بررسی و اصلاح شدند.
9. پوستهٔ اصلی به سیاه، خاکستری و سفید تغییر کرد؛ سایدبار و حداکثر عرض صفحه اضافه شدند. در درخواست بعدی، پنج رنگ معنایی به چیپ‌ها و سربرگ **هر گام به‌صورت مستقل** اضافه شد: اصلی، موفقیت، هشدار، خطر و ثانویه.
10. ورودی هر گام باید قابل مدیریت باشد: چیپ روی کارت ویرایش همان ورودی را باز می‌کند؛ فهرست ورودی در تنظیمات امکان افزودن، ویرایش، حذف و تغییر مقدار متغیر را دارد. ویرایش JSON همچنان در دسترس است.

## cURL و دادهٔ حساس

11. کنار هر درخواست و گام HTTP، مدال cURL و کپی وجود دارد. کاربر صریحاً خواست cURL **هیچ مقدار را با `***` نپوشاند** و با URL، هدر، بدنه و فایل‌ها مستقیم در ترمینال اجرا شود. تاریخچهٔ عادی همچنان مقدارهای حساس را پیش‌فرض می‌پوشاند؛ مدال cURL دادهٔ واقعی را می‌گیرد.
12. دادهٔ runtime در SQLite محلی و خارج از Git می‌ماند. این شامل متغیرها، OTP، توکن‌ها و درخواست/پاسخ خام است. برنامه برای loopback و استفادهٔ محلی طراحی شده است.

## شواهد و محدودیت‌های فعلی

- ۳۸ تست خودکار Python در آخرین بررسی گذشتند. تست فلو کامل عمومی و تست preset CLM از transport شبیه‌سازی‌شده استفاده می‌کنند.
- رابط رنگ گام، چیپ ورودی، ویرایش و حذف ورودی و ماندگاری پس از reload با پایگاه دادهٔ آزمایشی جدا بررسی شد.
- cURL نمونهٔ JSON با مقدارهای واقعی از ترمینال اجرا و کپی مدال بررسی شد.
- تکمیل واقعی فلو CLM تا ارسال برای امضا با حساب، OTP، tenant و امضاکنندهٔ معتبر **تأیید نشده** است. هیچ نتیجهٔ شبیه‌سازی‌شده‌ای نباید به‌عنوان تست زنده معرفی شود.
- پیش از ادامهٔ کار، `git status --short` وضعیت دقیق تغییرات محلی را نشان می‌دهد. تاریخچهٔ انتشار عمومی از snapshot پاک شروع می‌شود؛ تاریخچهٔ محلی قدیمی برای انتشار مناسب نیست.
